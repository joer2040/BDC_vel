AI Driven Accrual Matching — Deployment Approach

Six-phase structured delivery from data foundation to go-to-market

1
Foundation & MVP Development
Connect S/4HANA Data Products to SAP Datasphere. Build Bronze ingestion layer across Journal Entry, Purchase Order, Supplier Invoice, and Company Code. Deliver a single-page SAC story with basic GR/IR exposure summary to validate the core data pipeline.
Datasphere Bronze Layer SAC MVP
Hack Phase
2
Build Classification Engine
Develop Silver layer GR/IR gap logic in SAP Databricks: exposure calculation (signed GR − IR), first-match classifier (Missing Invoice → Cross-Period → Qty Variance → Price Variance), POST / REVIEW / OBSERVE rules, and automated RCA narrative generation.
Databricks Silver Layer Rule Engine
Hack Phase
3
Integrate & Build Advanced Dashboards
Promote outputs to the Gold fact table and connect back to Datasphere via Delta Share. Build the full multi-page SAC story: Accrual Worklist, Variance Analysis, Vendor & GL Intel, and Data Integration views with Smart Insights and Joule enabled.
SAC Gold Layer Delta Share
Hack Phase
4
Refine, Test & Conduct UAT
Refine classification thresholds with finance SMEs (Siva's review). Validate GR/IR gap detection across all 5 company codes. Conduct UAT with Financial Controllers and Accounting Managers to confirm worklist accuracy and action rule alignment.
UAT 5 Company Codes SME Review
Build Phase
5
Velocity Deployment & GTM
Deploy the finalized BDC architecture into the KPMG Velocity environment. Package the Accrual Matching solution as a repeatable asset — delivering demo scripts, sales collateral, and client-facing documentation to support market adoption.
Velocity Demo Script GTM Collateral
Build Phase
6
Plan Future Enhancements
Monitor KPIs (close cycle time, manual effort eliminated, audit findings). Finalize build-phase roadmap: Isolation Forest anomaly detection model, automated S/4HANA accrual postback for POST items, and multi-currency exposure normalization.
